## 三、与方案的偏差（实现时按实际情况调整）

| 方案原文 | 实际做法 | 原因 |
|---|---|---|
| 音频地址规则用 `AddressByFileName` | 改 `AddressDisable` | 文件名地址撞车（`可琳：最快转速` 在 Billy/ 与 Corin/ 各一份），`EditorSimulateBuildPipeline` 直接构建失败并拖垮整个 ui 包 |
| 受击 HIT 走 `NotifyDamageClientRpc` 同步 | 不新增同步 | 实测远端镜像端状态机本来就会各自播一次受击/闪避，加 RPC 反而双声 |
| Compete 侧只改类型引用 | 删掉 4 行音频调用 | `Compete.ComboData` 与全局 `ComboData` 不是同一类型，且该组件从未挂载（调用恒为空操作） |
| 用序列化直接写 `m_ExposedParameters` | 走内部 API `AddExposedParameter(AudioGroupParameterPath)` | 直写 GUID 只有 Master 生效；且 Unity 按组名字母序排参数，必须按 GUID 匹配后重命名 |
| `GameSettings.SfxScale` 保留供旧代码 | 调用点全部移除，属性保留但零调用 | 属性仍在 `GameSettings` 上，若后续 Lua/新代码需要可继续用 |

## 四、遗留事项

1. **双客户端听感验证**（9.5）：需 Host + Client 双进程实测；建议在 `multiplecompete` 场景打一局，确认远端角色的连招台词/挥击音能听到、自己没有双声、脚步不刷 RPC。
2. **出包前必须真正 Collect + Build 一次**：编辑器模拟模式每次启动都会 `EditorSimulateBuild`，所以编辑器内不需要打包；但出安装包时 `Assets/Content/Resource/audoi` 必须被打进 `ui` 包，否则路径加载全失败（会 LogError 带 location）。
3. **`UiFx` / UI 点击音未接入**：项目目前没有 UI 音效，若需要可用 `PlayOneShotWith2DUI` 接。
4. **BGM 目前无人调用**：`PlayerBgAudio` 能力就绪，但主界面/战斗还没有 BGM 配置，需要业务侧决定曲目。
5. **`EffectPlayer.prefab` 统一了 3D 衰减参数（1/30/Linear）**：若某个角色需要特殊距离，需要给 `PlayEffect` 加可选覆盖参数（当前未做）。
