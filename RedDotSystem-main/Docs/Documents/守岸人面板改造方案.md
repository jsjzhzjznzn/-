# 守岸人面板改造方案（原"阿福"AI 助手）

> 2026-10-23 | 需求：把 AI 助手「阿福」改名为「守岸人」、换成鸣潮风格头像；面板支持拖动与缩放；对话区美化并修复"看不清字"。

---

## 1. 现状与问题定位

### 1.1 面板现状（Assets/Game/UI/Agent/AgentView.prefab）

| 节点 | 现状 |
| --- | --- |
| AgentView（根，1920×1080 全屏） | 挂 `PanelSkin`（applyLightTheme=true，backgroundKey 空 → 通用羊皮纸底） |
| AgentPanel（700×620 居中） | 深色圆角底 `afu_round_lg #262B33` |
| ChatTitle | 文案「阿福」，22px 浅灰 |
| MessageList（660×392） | 深色底 `afu_round_md #1F242B` |
| MessageLeftTemplate | 深灰底 `#2E333D` + 15px 浅灰字 |
| MessageRightTemplate | 钢蓝底 `#4D647D` + 15px 白字 |
| ChatInput | 深色底 + 15px 浅灰字，占位文案过长（约 28 字 + 英文，超出 566px 输入框） |
| 头像 | `Resources/Agent/afu_avatar`（52px）+「福」字占位 |

### 1.2 "看不清字"的真正原因（不是字体问题，是配色逻辑冲突）

`PanelSkin.Recolor()` 在面板 `OnEnable` 时做浅色主题转换：

- **TMP 文本**：亮度 > 0.42 的一律改成深棕色 `UITheme.TextMain(0.263,0.251,0.227)`；
- **Image**：只翻"没有 sprite 的深色块"，`if (img.sprite != null) continue`。

而阿福面板的气泡底和消息区底**全部是带 sprite 的九宫格图**（`afu_round_md`），不会被翻色，仍保持深色（0.122~0.302）。结果就是：

> 深色气泡底 + 被翻成深棕的字 = 对比度near 1:1，正文几乎不可见。
> 消息区整块仍是深色 `#1F242B`，在米色面板里看起来就是一个"黑洞"。

截图里的大黑块正是这个组合（不是"没渲染消息"）。

次要问题：
- 字号 15px 在 1920×1080 参考画布下渲染到 1280/720 屏幕后仅约 10px 物理像素，偏小；
- 输入框占位文案超宽，被裁切成"半句话"。

### 1.3 现有交互能力

- 只能居中显示，**不可拖动、不可缩放**；
- 面板开合补间（`AgentTweenFx.ShowPanel/HidePanel`）直接读写 `localScale` 与 `anchoredPosition`，新增缩放/拖动必须与之协同；
- 悬浮球（`AgentFloatBall`，程序化 UI）与主页入口按钮（`HomeView.agentButton`）也是"阿福"形象的一部分。

1. **改名**：所有玩家可见处由「阿福」→「守岸人」（客户端 UI + 服务端网关提示 + AI 人设/欢迎语/简报/主动提醒）。
2. **换头像**：`Assets/Content/Resource/ui/mingchao/T_IconRoleHeadCircle256_1_UI.png`，用于面板头像、气泡小头像、悬浮球、主页入口图标。
3. **可拖动 / 可缩放**：整块面板拖动改位置、按钮（或 Ctrl+滚轮）缩放 0.80×~1.50×，位置与缩放跨会话记忆。
4. **对话区美化 + 可读性**：浅色羊皮纸底 + 深棕正文 + 金色描边，排版留白加大、字号提升，输入框提示缩短。

### 3.2 头像

   → `Assets/Game/Resources/Agent/shouanren_avatar.png`（Sprite/Single，256px，与现有 `afu_avatar` 同目录同规格，`Resources.Load` 可直接取）。

### 3.3 可拖动

- 在 `AgentView`（全屏视图根）上实现 `IBeginDragHandler/IDragHandler/IEndDragHandler`。命中点在面板矩形内、且不在交互控件（Button/InputField/ScrollRect）上时，才进入拖动。
- 位移用 `RectTransformUtility.ScreenPointToLocalPointInRectangle(父级, ...)` 换算（避免 canvas 缩放系数问题）。
- 拖动开始即 `Kill` 开合补间，并把 `panelRestPos` 更新为当前坐标（下次开合从新位置进/出）。
- 位置按"考虑缩放后的面板尺寸"钳制在父级矩形内，不让面板拖出屏幕。
- 持久化：`afu_panel_pos_x / afu_panel_pos_y`（PlayerPrefs），打开面板时读取并钳制。

### 3.4 可缩放

- 采用**整块等比缩放**（`AgentPanel.localScale`），而不是改 RectTransform 尺寸：面板内部是绝对坐标布局，改尺寸不会重排，等比缩放才能保证"放大后字、气泡、间距一起变大"。
- 档位：0.80 / 0.90 / 1.00 / 1.15 / 1.30 / 1.50，默认 **1.15**（补偿 1920 参考画布，等效正文 ≈17px）。
- 入口：标题栏新增 `−` / `+` 两个 40×40 按钮（`ZoomOutButton` / `ZoomInButton`，走 `[ControlBinding]`）；另支持 **Ctrl+滚轮** 在面板上缩放（可选增强，带 `IScrollHandler`）。
- 缩放以面板中心为轴心，缩放后立即做一次边界钳制；持久化 `afu_panel_scale`。
- 与开合补间的协同：`AgentTweenFx.ShowPanel/HidePanel` 增加 `restScale` 参数，补间在 `restScale*0.97 ↔ restScale` 之间动，不再写死 1。

> 不采用"拖右下角改尺寸"：内部布局是手摆坐标，拉伸会造成文字错位；等比缩放是移动端最直观且不会破版的做法。

### 3.5 对话区美化

配色（浅色羊皮纸 + 金线，与主页原神风一致）：

| 元素 | 新值 |
| --- | --- |
| 消息区底 | 米白 `#FDF8EE`，1px 金线描边 `rgba(200,168,96,0.45)`，圆角 18 |
| 守岸人气泡 | 近白 `#FFFDF7` + 极淡金边，正文 `#3B332B` 17px，行距 +8% |
| 玩家气泡 | 淡金 `#F2E1BC`，正文 `#3B332B` 17px |
| 气泡尾巴 | 与所属气泡同色 |
| 输入框 | 米白 `#FFFDF8` + 金边，正文 `#3B332B` 16px，占位 `#8C8071` |
| 发送按钮 | 金色 `#D9B96B`，深棕字 |
| 标题 / 签名 | `#4A3F30` 24px / `#8A7C68` 14px |
| 状态行 / 思考指示器 | `#7A6E5E` 14px；指示器底米白 + 金点 |

排版：
- 气泡内边距 12/10 → 14/12，气泡间距 6 → 8，左右边距 12 → 16；
- 消息区顶/底留白 12 → 16；

- 守岸人小头像 26 → 30px，与气泡间距 8 → 10。

> 这些值写进预制体（离屏烘焙），不依赖 `PanelSkin` 的自动翻色：`PanelSkin.Recolor` 只改"亮度>0.42 的文字"和"无 sprite 的深色块"，我们的正文已是深色、底图带 sprite，因此不会被二次改坏。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 拖动层吃掉 ScrollRect/输入框/按钮的拖拽 | 只在"按下点不在 Selectable 子树内"时启动拖动；滚动区自身实现 IDragHandler，事件优先给它 |
| 缩放与开合补间互相覆盖 | 补间只写 `restScale*0.97` 与目标之间，结束时钉到 `restScale`；缩放按钮在 `panelBusy` 时忽略 |
| `PanelSkin` 再次翻色破坏对比度 | 正文烘焙为深色（亮度<0.42 不翻）、底图带 sprite（不翻）；验收项 2 做数值兜底 |
| 预制体被 `AgentViewBuilder`（PanelMigrator）重跑覆盖 | 该工具是从场景迁移的一次性工具（场景 canvas 已删），不会被日常跑；美化脚本单独成菜单 |
| 改名遗漏导致 AI 自称"阿福" | 人设、简报、主动提醒、长期记忆提示词全部改；验收用一次真实对话确认自称 |
| 服务端未重启时仍是旧文案 | 文案改动需重启 competeserves 与 AgentServer，文档中标注 |
