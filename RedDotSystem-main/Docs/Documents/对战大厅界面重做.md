# 对战大厅界面重做（BattleLobbyView）

> 目标工程：`D:\tuanjieproject\frined\RedDotSystem-main`　日期：2026-10-21
> 问题：`对战` 面板是 P3 阶段生成的深色 HUD 风格（纯深灰底 + 直角大色块按钮 + 小红叉关闭），
> 与设置面板的浅色手绘风不统一，视觉廉价。

## 1. 设计口径

沿用项目现有的一套 UI 资源与色板（`Assets/Game/Scripts/UI/Settings/Editor/SettingsPrefabBuilder.cs` 同源）：

| 角色 | 取值 |
|---|---|
| 背景 | `ui/Theme/blur_home.png`（主页虚化底，全屏拉伸 + 0.52 中性压暗） |
| 面板底 | `ui/Theme/panel_bg.png` 羊皮纸底图（金色描边 + 四角藤蔓），九宫格 border=200；缺失时退回 `#F6F1E7` + `panel_round.png` |
| 主文字 / 次文字 | `#43403A` / `#8C8578` |
| 强调金 | `#D9B25C`（标题竖条、分隔线、主按钮） |
| 次按钮 / 关闭键 | `#EDE3CE` / `#E8DFCB` + `btn_round.png` / `circle.png` |
| 字体 | `Assets/Codely/Fonts/NotoSansSC-Regular SDF.asset` |

版式（面板 760×520，1920 参考分辨率下约占 40% 宽）：

- 全屏虚化背景 → 面板投影（偏移 -10px，16% 黑）→ 面板本体（羊皮纸底图）；
- 居中标题「对战」44 号粗体，下接副标题「房主即服务端 · 端口 7777」——
  底图四角有藤蔓装饰，标题靠左会压在花枝上，所以走居中；
- 金色细分隔线（50% 透明）；
- 右上圆形 `closeButton`（"×"）；
- 两个 560×86 的操作条：**创建房间**（金色底 + 深字，主操作）/ **加入房间**（米色底），
  每条带一行 14 号小字说明（"作为房主开局 · 好友填写你的 IP 加入" / "输入房主的 IP 后连接"），
  按钮自己解释后果，省掉一段说明书；
- 底部居中的 `statusText`（运行期被 SetStatus 覆写）。

## 2. 实现方式

新增编辑器构建器 `Assets/Game/Scripts/UI/Battle/Editor/BattleLobbySkinBuilder.cs`，
菜单 **Tools/UI/重建对战大厅**，覆盖式重建 `Assets/Game/UI/Battle/BattleLobbyView.prefab`：

- 只重写这一个预制体，**不动** BattleRoomView / JoinRoomView / 联机预制体（那些仍归 `Tools/Battle/P3 一键构建`）；
- 控件名与 `BattleLobbyView` 的 `[ControlBinding]` 字段一一对应（panel / titleText / subtitleText /
  createRoomButton / joinRoomButton / closeButton / statusText），绑定表由构建器写入 `UIControlData`；
- 根节点必须挂 `BattleLobbyView`（UIView）本体 —— 漏了 UIManager 打不开面板，构建器已显式补上；
- 圆角底图复用 `Assets/Game/Resources/UI/Theme` 下的 panel_round / btn_round / circle（缺失时自动生成）。
