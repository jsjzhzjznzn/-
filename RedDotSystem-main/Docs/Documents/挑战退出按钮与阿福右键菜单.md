# 挑战 HUD 退出按钮 + 阿福悬浮球右键菜单

> 目标工程：`D:\tuanjieproject\frined\RedDotSystem-main`　日期：2026-10-21
> 需求：① 挑战界面加退出按钮；② 阿福悬浮球支持右键弹出选项菜单并能关闭。

## 1. 挑战 HUD 退出按钮

### 现状
`ChallengeHudView` 只有一个"结算面板"里的 `HomeButton`（回主页），战斗中（`resultPanel` 未激活时）没有任何退出入口，玩家只能打完或被击杀才能离开。

### 方案
- 在 `Assets/Game/UI/Challenge/ChallengeHudView.prefab` 根节点下新增常驻按钮 **ExitButton**（右上角，160×56）：
  - 位置：`anchorMin = anchorMax = (1,1)`、`pivot = (1,1)`、`anchoredPosition = (-48,-48)`；
  - 外观直接克隆现有 `HomeButton`（同底色 0.18/0.42/0.78、同 TMP 字体与字号），保证和结算按钮一致；
  - 文本"退出"。
- 绑定仍走框架 `[ControlBinding]`：在 `UIControlData.ctrlItemDatas` 里补 `exitButton → Button` 条目（与 retryButton/homeButton 同结构）。
- 为避免误触，**两次点击确认**：第一次点击只把 hint 改成"再点一次退出挑战"，2 秒内再点才真正退出（`CloseAndLoadAsync("zhuye")`，复用结算面板的离场逻辑：关 HUD → 恢复 timeScale → 带加载页切场景）。
- 生成方式：新增编辑器脚本 `Assets/Game/UI/Challenge/Editor/ChallengeHudPrefabBuilder.cs`（菜单 `Tools/Challenge/重建 HUD 退出按钮`），幂等——已有 ExitButton 就只更新位置/文本，不重复创建。这样 prefab 丢失或改版后能一键重建，不用手改 YAML。

| `Assets/Game/Scripts/UI/Challenge/ChallengeHudView.cs` | 新增 `[ControlBinding] exitButton` + 两次点击退出逻辑 |

## 2. 阿福悬浮球右键菜单

### 现状
- 悬浮球（`AgentFloatBall`，程序化构 UI，DDOL 常驻）只有：左键单击 = 打开阿福面板/场景提示；双击 = **彻底隐藏且只有重新登录才恢复**。
- 没有右键入口；玩家双击后球消失，界面上找不到任何把它叫回来的方式 → "没有悬浮窗了"。

### 方案
1. **右键弹出菜单**（`OnPointerUp` 里判 `PointerEventData.InputButton.Right`，不参与单击/双击判定）：
   - 菜单贴着球弹出（球在右半屏则翻到左侧），超出屏幕自动钳回；
   - 两个选项：**打开阿福** / **关闭悬浮窗**；
   - 全屏透明遮罩承接点击 → 点空白处收起菜单；选完自动收起；
   - 样式沿用本文件的程序化 UI 工具（`afu_round_md` 深色圆角底 + 金色字），层级与球同级。
2. **关闭** = 现有的"本次登录隐藏"（`hiddenByUser`），但提示改成"阿福收起来了，点主页的阿福入口可以叫我回来"。
3. **恢复入口**：`AgentView` 打开阿福面板时（`NotifyAgentPanelOpen(true)`）顺手 `hiddenByUser = false`；
   面板关闭后球自然回到屏上。这样"关掉 → 想找回 → 从主页阿福入口开一次面板"就闭环了。
4. 保留双击隐藏（2026-10-17 定稿行为），只是多一条可发现、可恢复的路径。

| `Assets/Game/Scripts/Agent/AgentFloatBall.cs` | 右键菜单构建/交互、关闭项、面板打开时恢复、类注释更新 |

## 3. 验收

- [ ] 挑战场景右上角有"退出"按钮，不遮挡计时/血条。
- [ ] 单击一次 → hint 提示"再点一次退出挑战"；2 秒内再点 → 回主页；超时后再点只重新计时。
- [ ] 结算面板出现时退出按钮仍可用，`leaving` 守卫防止重复切场景。
- [ ] 悬浮球右键 → 菜单出现在球旁，不被屏幕边裁掉。
- [ ] 点"关闭悬浮窗" → 球消失 + 提示；随后从主页打开阿福面板再关闭 → 球回来。
- [ ] 点"打开阿福" → 主页打开面板；其它场景给提示。
- [ ] 菜单打开时点空白处收起；不挡其它 UI 点击（遮罩关闭后销毁/失活）。
- [ ] 编译 0 error，控制台无 ControlBinding "can not find binding" 报错。
