# 共鸣者影像簿（角色档案页）设计方案

> 状态：**已实施**（2026-10-29；实测结论见 §6）
> 需求来源：「点击第二张图的按钮 出现第一张图片的ui界面，尽可能模仿；背景用视频（先用图片顶替）；用我的 UI 框架；也可以用 mingchao/touxiang 的头像」
> 参考素材：鸣潮「共鸣者影像簿」截图、主页玩家名片（`冒险者 · ID N`）、大世界实机录像

## 0. 需求拆解

| # | 需求 | 落地 |
|---|---|---|
| 1 | 点第二张图的按钮 | 主页左上「冒险者 · ID N」名片整块变成按钮，点击打开本页 |
| 2 | 出现第一张图的 UI | 全屏「共鸣者影像簿」：左侧资料面板（头像/昵称/特征码/签名/信息行/角色卡/编辑按钮）+ 左上标题 + 右上拍摄与关闭 + 右下特征码 |
| 3 | 背景是视频 | 全屏背景节点先放静态大图顶替（`ui/Theme/home_bg.png`）；换真视频时只改这一个节点 |
| 4 | 用现有 UI 框架 | `UIView` 子类 + `UIType.ProfileView` + `UIConfig.json` 注册 + 编辑器构建器（菜单一键重建） |
| 5 | 用 mingchao 头像 | 玩家头像用 `T_IconRoleHeadCircle256_1_UI`，角色卡用 `T_IconRoleHead80_1/2_UI` |

### 已确认的取舍

| 取舍 | 决定 | 理由 |
|---|---|---|
| 背景 | **静态图**（`home_bg.png`），视频暂不接 | 用户明确「背景先不播放视频，随便找一张图片假装是视频」。视频源文件留在 `screenshots/`，换回时把 `Backdrop` 节点换成 `RawImage + VideoPlayer` 即可；`Assets/Game/UI/Profile/Video` 已删除，避免 3.4MB 录屏打进入 ui 包 |
| 右侧大图 | **不做** | 用户确认「不需要右边的卡片」；右侧留给背景本身 |
| 角色卡 | 2 张（安比/艾莲），头像用 mingchao 圆形头像 | 项目只有这两个角色；mingchao 的 80px 头像是裁好的圆形头像，直接铺满圆框，不必再裁立绘（之前用立绘裁头，艾莲那张是带标题的海报，会把「ELLEN JOE」裁进圆框） |
| 美术来源 | 全部在构建期烘进预制体（Sprite 直接引用） | 运行时零加载：之前用 ResourceManager 按完整路径异步加载，`Assets/Content/...` 不在 ui 包收集范围，sprite 全是 null，界面出现白方块 |
| 编辑类入口 | ⋮ / ✎ / 签名 / 编辑影像簿 / 拍摄 / 眼睛 = 状态条提示「暂未开放」；复制特征码真实可用 | 项目没有昵称/签名/头像上传系统，做假编辑没有数据落点 |
| 暂停 | 打开 `PauseManager.Push(Other)`，关闭 Pop | 全屏资料页打开时世界该冻结；实测关闭后 `timeScale` 回到 1 |
| 关页时机 | 关闭键 / Esc / 点右侧空白 / 切场景自关 | 全屏页常驻对象池，切场景不收会盖在新场景上 |

## 1. 现状与关键事实

- 主页名片由 `HomeViewSkinBuilder.BuildPlayerInfo` 程序化生成：`playerInfo`（320×60 胶囊）+ `InfoFill / Avatar(AvatarFill+AvatarGlyph「冒」) / playerInfoText`，原先**没有 Button**。
- `Assets/Content/Resource/ui/mingchao/touxiang` 下是 12 张 80×80 圆形头像 + 1 张 256 圆形头像，均已是 Sprite 导入（`spriteMeshType=FullRect` 以外的默认设置也够用，四角透明）。
- 头像/立绘如果不是本项目 `Assets/Game/Resources` 或 ui 包收集目录下的资源，`ResourceManager` 找不到；**构建期直接引用 Sprite 最稳**。
- 框架绑定（`UIControlData.BindDataTo`）在本页预制体上不可靠：`UIView.OnInit` 时机下字段反射与 `ctrlItemDatas` 的写入都容易静默失败（本次实测绑定条目数为 0）。本页改为**按节点名运行时查找**，改名即失效、不会假成功。

## 3. 数据

- 玩家：昵称固定「冒险者」，特征码 = `ClientNetworkManager.MyPlayerId`（未登录显示 `--`）。
- 生日 / 索拉等级 / 联觉等级：展示元数据（常量 5月1日 / 5阶 / 40级），项目没有对应养成系统。
- 角色卡：名字取 `BattleHeroCatalog.Get(i).DisplayName`，头像由构建器烘入；选中索引存 `PlayerPrefs("Profile.LastChar")`。

## 5. 实现要点（踩过的坑）

1. **Mask 必须与圆形图同节点，被裁图必须是它的子节点**。把 `Mask` 挂成一个兄弟节点、图放在旁边，等于完全不裁——卡片头像是方形整图，视觉上就是「卡片里有张海报」。
2. **实心圆角图不能当边框用**。`card_frame` 原本是实心圆角块，涂金色后整张卡泛黄；改成「外圆角 − 内圆角」的描边环才对。
3. **右对齐文本要用右上 pivot**。用左上 pivot 再给负 x，框会从锚点往右长，数值直接跑到面板外。
4. **预览/贴图不能留空 sprite**。`Image` 的 `sprite == null` 会渲染成白色方块，很容易被误判成「图片没加载」。
5. **8 位径向渐变在整屏尺寸下必然出现同心圆带**，暗角改用「整块半透明黑 + 背景亮度」处理。
6. **`PauseManager` 停顿期间 `WaitForSeconds` 不推进**，E2E 脚本一律用 `WaitForSecondsRealtime`。
7. 主页场景（`zhuye`）直接进 Play 时 `UIManager` 未初始化，脚本要先 `UIManager.Open(HomeView)` 拉一次自举；UI 是 `ScreenSpaceCamera`，屏幕坐标要用 `canvas.worldCamera` 换算才打得准。

## 6. 验收（Play Mode，zhuye 场景）

| # | 用例 | 结果 |
|---|---|---|
| P1 | 鼠标点主页名片 | 射线命中 `InfoFill` → 冒泡到 `playerInfo` 的 Button → `ProfileView` 打开 |
| P2 | 背景 | `Backdrop` 的 Image sprite = `home_bg`，全屏铺满，无灰底/黑块 |
| P3 | 角色卡 | 2 张，头像为 mingchao 圆形头像；点第 2 张后金框（alpha 1.00）与下划线移动，第 1 张降到 0.28 |
| P4 | 文案 | 昵称「冒险者」、特征码 `--`（未登录）、三行信息 `5月1日 / 5阶 / 40级` |
| P5 | 复制 | 未登录时提示「尚未登录，没有可复制的特征码」；登录后写入剪贴板 |
| P6 | 关闭 | 关闭键关闭；关闭后 `PauseManager.IsPaused == false`、`Time.timeScale == 1`、光标 `Locked` |
| P7 | 切场景 | `activeSceneChanged` 自关 |
| P8 | 版面 | 抓帧核对：左侧三栏式资料面板、金色强调、右侧背景不被遮挡、右下特征码与眼睛按钮不重叠 |

## 7. 风险 / 后续

| 项 | 说明 |
|---|---|
| 背景视频 | 现在是静态图。接真视频时把 `Backdrop` 换成 `RawImage + VideoPlayer(RenderTexture)`，注意解码出画前先隐藏 RawImage（空 RT 是灰底） |
| 角色卡身份 | 卡名是安比/艾莲，头像是 mingchao 头像包（蓝帽少女 / 红发少女），属于占位美术；有专属头像后替换 `CardHeadPaths` 即可 |
| 玩家头像 | 用 `T_IconRoleHeadCircle256_1_UI` 占位，接头像系统后换 |
| 右侧留白 | 移除大图后右侧只剩背景，若后续想让页面更「满」，可加一行角色名 + 星级标签，或把背景换成分辨率更高的主视觉 |
