# 角色攻击索敌（Auto Aim / 软锁定）设计与实现

> 2026-10-24 | 范围：玩家近战轻击（`CharacterCombo`），挑战场景 BOSS
> 目标：解决「看起来对准了却打空」，同时不剥夺玩家对攻击方向的控制权

---

## 0. 结论

- 索敌是**软锁定**，不是硬锁：它只在「起手 → 命中帧前」修正朝向，命中帧后锁死。
- 核心不是"选谁"，而是**"选完之后还要跟住"**。原实现只在起手 0.1s 内转向，之后不再跟，
  目标一动就空——这是之前打空的主因。
- 玩家有方向输入时，索敌必须让路（只做微调，不逆着玩家拉人）。

---

## 1. 改前 / 改后

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 转向窗口 | 固定 0.1s（smoothstep 插值） | **连招全程**：锁定目标存活就一直跟（含命中后） |
| 转向速度 | 0.1s 内可转 180°（≈1800°/s，瞬转） | 角速度上限 **720°/s**，可调 |
| 目标选择 | 每段起手重新评分 | **连招内保持原目标**；死亡/超距/无视线才换 |
| 夹角上限 | 180°（背对也吸） | **130°**（只用于首次选目标；已锁定的目标不受限） |
| 视线 | 无 | `Linecast`（只打 environment，隔墙不锁） |
| 攻击我者 | 加分代码被注释（AI 未移植） | 用 `EnemyBrain.IsAttacking && Target == player` **恢复加分** |
| 玩家意图 | 无 | 方向输入与目标夹角 > **60°** 时**不参与首次选目标/粘刀**（已锁定目标仍然跟随） |
| 目标粘滞分 | 0.15 | 0.35 |
| 命中后 | 锁定朝向（粘刀） | **不再锁定**：继续跟随目标（玩家反馈"连招要一直面向怪"） |

---

## 2. 设计原则

1. **玩家意图优先（只影响选目标）**：有方向输入时，首次选目标只吸 60° 以内的；一旦锁定，连招期间始终面向它。
2. **锁定后整段跟随**：从起手到收招都保持朝向；命中帧不再停转，避免"打完一刀就背对"。
3. **一次连招锁一个目标**：中途切线会让连段打散；只有目标失效才换。
4. **转向、位移是两件事**：
   - 转向：锁定的目标存活就一直跟，角速度限制避免瞬转；
   - 位移：只补"差一点点"（`TryStickToTarget` ≤0.35m，带 CharacterController 碰撞）。

---

## 3. 分层

```
Layer 0  玩家意图：方向输入（相机相对）> 无输入时用角色当前朝向
Layer 1  目标选择（起手一次；连招内保持）
         过滤：存活 / enemy 层 / 距离 ≤ autoAimRadius / 夹角 ≤ autoAimMaxAngle
                / 视线通 / 不逆着玩家输入
         评分：距离权重 + 夹角权重 + 正在攻击我 + 目标粘滞
Layer 2  朝向对齐（起手 → 收招，全程）
         每帧 RotateTowards，角速度 autoAimTurnSpeed；已锁定目标不再受夹角限制
Layer 3  位移补正（命中帧前）：差 ≤0.35m 微冲（带碰撞）
```

## 4. 参数（`PlayerComboSOData`，全部可在 PlayerSO 资产里调）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `autoAimEnabled` | true | 仅单机；联网朝向由 NetworkTransform 同步 |
| `autoAimRadius` | 5m | 搜索半径 |
| `autoAimMaxAngle` | 130° | 超过不吸（背对不硬转） |
| `autoAimDistanceWeight` | 0.5 | 距离评分权重 |
| `autoAimAngleWeight` | 0.5 | 夹角评分权重 |
| `autoAimAttackingMeBonus` | 0.3 | 正在攻击我的敌人加分 |
| `autoAimStickyBonus` | 0.35 | 上一目标加分 |
| `autoAimTurnSpeed` | 720°/s | 转向角速度上限（≤0 不限速） |
| `autoAimInputRespectAngle` | 60° | 有输入且目标在这之外 → 不参与首次选目标/粘刀（已锁定目标仍跟随） |

> 注意：`Playeranbi.asset` 里 `PlayerComboSOData` 是内联序列化且**没有这些字段的旧值**，
> 所以直接吃代码默认值；要按角色单独调，就在 Inspector 里改一次让资产写入。

## 6. 实测（Play，`tiaozhan`）

```
A 连招全程面向：起手 0.12s 后把 BOSS 移到侧后方（偏离 75°）
   maxErrAfterMove=75.0°  lastErr=0.0°
   → 连招期间一直转到面向目标（含命中后），不再"打完一刀就背对"
B 前摇被打：BOSS 出招前摇（normalized 0.10）时受击
   actionAfter=Hurt  → 切受击成功
C 判定帧被打：BOSS 判定帧（normalized 0.40）时受击
   actionAfter=Attack → 只有这一刀挥出去时霸体
```

## 7. 未做 / 后续

- **输入尊重的 E2E**：需要模拟 Input System 的摇杆输入（当前只在代码逻辑层验证）。
- **锁定模式（硬锁）**：ZZZ/WuWa 式相机看向 + 移动环绕；挑战是 1v1，收益有限。
- **起手突进**：目标在 1.5~3m 且本段是突进招时按曲线前冲 0.6~1.2m（目前只有命中帧 0.35m 微冲）。
- **多目标优先级**：镜头中心/被围殴时的目标切换策略（当前 1v1 用不到）。

## 8. 同轮调整：受击规则（怪物）

最终定稿（2026-10-24，取代"分层抖动"版本）：**打中就把怪切到受击状态，连打就一直受击**。

| 项 | 规则 |
| --- | --- |
| 轻击 | 进 `HurtAction`，片段 `Hit_Shake`（0.42s），受击时长 `flinchSeconds`（0.8s） |
| 重击 | 进 `HurtAction`，按命中方向选 `Hit_L_Front` / `Hit_L_Back`，0.9s、1.8× |
| 连打 | `HurtAction.Refresh()` 只延长计时、**不重播片段**；片段播完手动 wrap 归一化时间继续循环 |
| 打断 | 任何阶段被打都会切受击（**取消判定帧霸体**） |
| 破防 | 韧性打空 → `Debuff_Stun_Start` 硬直（不可被普通受击打断） |
| 顿帧 | 玩家打怪不再顿帧（`HitFeelProfile.hitStopOnPlayerHit=false`），震屏/特效/音效/闪白/击退保留 |

实现：`EnemyBrain.OnDamaged`（统一走 Hurt + Refresh）、`HurtAction.Refresh/loopClip`、
`AttackAction.CanBeInterruptedBy(Hurt)=true`、`HitFeelService` 的顿帧开关。

实测：出招中被打 → `action=Hurt`、`timeScale=1.00`；0.3s 后再打 `NormalizedTime 0.80→0.82`（不重播）；
连打 8 刀一直处于 Hurt（中途破防转 Stagger），从未回到 Attack。
