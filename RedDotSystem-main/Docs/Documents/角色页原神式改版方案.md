# 角色页原神式改版方案

> 状态：设计待确认（2026-10-27）。本文只描述采用的一版设计。确认第 8 节的取舍后实施。

## 1. 目标与边界

把现有角色页（`CharacterView`，UIType 25）改成参考图的版式与视觉语言：

- 暖金色全屏背景，中央全身 3D 模型，左右无实色面板，文字直接叠在背景上。
- 顶部圆形头像切换，左侧竖排功能菜单，右侧属性列表，右下主按钮。
- 武器选择复用现有能力，不再新增协议或数据表。

**不做 1:1 复刻**：参考图中的等级/经验、命之座星数、元素徽章、圣遗物、天赋、资料、体力上限、元素精通、升级按钮，本项目没有对应数据或系统。本期直接不显示，不用假数据占位。

## 2. 参考图与项目能力映射

| 参考图元素 | 本项目 | 处理 |
| --- | --- | --- |
| 顶部圆形头像栏（10 个） | `BattleHeroCatalog` 2 个角色（安比/艾莲） | 横向 2 个头像，选中加青色下划线 |
| 左上元素徽章 + 名字 | 无元素系统 | 只显示角色名 + “角色”小字，图标用菱形几何 |
| 左侧菜单：属性/武器/圣遗物/命之座/天赋/资料 | 只有属性与武器 | 只做“属性 / 武器”两项 |
| 中央全身立绘 + 地面倒影 | `UIModelManager` 渲到 `RawImage` 的 3D 预览 | 保留模型与拖动旋转；倒影本期不做 |
| 右侧角色名 / 命星 / 等级经验 | 只有名字与武器 | 名字 + 当前武器名；无命星/等级 |
| 右侧五维属性 | 6 项现有属性 | 生命上限/攻击/防御/增伤/减伤/移速 |
| 详细信息按钮 | 无详情页 | 用“更换武器”次按钮替代 |
| 角色简介 | 无 | 用一行功能说明替代（基础值 + 装备加成） |
| 右下“升级”主按钮 | 无等级系统 | 主按钮改为“更换武器” |
| 左下九宫格 / UID | 无 | 不做 |

## 3. 布局规格

参考分辨率 1920×1080，全部按左上/右上锚点排布，窗口缩放由 CanvasScaler 处理。

### 3.1 背景

- 全屏 `Image`，铺满，不接收点击（`raycastTarget=false`，避免挡住下层按钮）。
- 暖金竖向渐变：顶部 `#F2D08A` → 中部 `#D9AE62` → 底部 `#A9742F`；叠加柔和的云层与光点。
- 右侧属性区上方叠一层从左到右的暗色渐变（`#000000` alpha 0 → 0.28），保证白字可读，不形成明显矩形面板。

### 3.2 顶部

| 元素 | 锚点 | 位置 | 尺寸 |
| --- | --- | --- | --- |
| 角色名 | 左上 | (72, -56) | 420×40，30px 白色 |
| “角色”小字 | 左上 | (72, -92) | 200×22，14px 灰白 |
| 头像行 | 顶部居中 | (0, -44) | 2×84，间距 18，整体居中 |
| 选中下划线 | 头像下方 | y=-6 | 48×3，青色 |
| 关闭键 | 右上 | (-48, -28) | 48×48 |

头像：圆形裁切（`RectMask2D` 或圆形遮罩），竖版立绘按顶部对齐放大裁切；选中头像描边加亮，未选中 alpha 0.75。

### 3.3 左侧菜单

| 项 | 位置 |
| --- | --- |
| 菜单根 | 左上 (72, -300)，宽 260，高 140 |
| 属性 | 第 1 行 y=0，24px |
| 武器 | 第 2 行 y=-56，24px |

每行 = 左侧 10×10 菱形（旋转 45° 的 `Image`）+ 文字。选中：文字纯白 + 菱形青色；未选中：文字 60% 白。

### 3.4 中央模型

- 预览根：左上 (430, -110)，1040×900（比现在更宽更高，给全身留空间）。
- `RawImage` 铺满预览根，`raycastTarget=true`（拖动旋转）。
- 不显示底部角色名/武器类型（移到右侧）。
- 模型脚底加一个 240×36 的深色椭圆（alpha 0.18）作为落地阴影；不做镜面倒影。

### 3.5 右侧属性区

| 元素 | 锚点 | 位置 | 尺寸 |
| --- | --- | --- | --- |
| 属性根 | 右上 | (-72, -120) | 420×780 |
| 角色名 | 左上 | (0, 0) | 420×48，34px |
| 当前武器 | 左上 | (0, -52) | 420×24，16px 灰白 |
| 分隔线 | 左上 | (0, -88) | 420×1，白色 alpha 0.25 |
| 属性行 ×6 | 左上 | y=-112 起，行高 48 | 420×40 |
| 功能说明 | 左上 | (0, -430) | 420×60，14px 灰白 |
| 更换武器（次按钮） | 左上 | (0, -510) | 220×48，半透明灰 |

属性行 = 12×12 菱形图标 + 标签（18px 灰白）+ 数值（22px 白色，右对齐）。行内容：

1. 生命值上限
2. 攻击力
3. 防御力
4. 增伤
5. 减伤
6. 移速

数值口径沿用现有 `RefreshAttributes`：基础白值来自 `PlayerSO.statsData`，加成来自 `EquipmentManager.GetEquipAttrBonus`。增伤/减伤/移速显示百分比。

### 3.6 底部

| 元素 | 锚点 | 位置 | 尺寸 |
| --- | --- | --- | --- |
| 主按钮 | 右下 | (-72, 48) | 240×64，米白底 + 深色文字 |
| 提示 | 左下 | (72, 36) | 600×24，14px 灰白 |

主按钮文案：属性页 = “更换武器”；武器选择器打开时隐藏。

## 4. 交互与页签

- 进入页面默认选中上次角色（`PlayerPrefs` 现有逻辑保留），默认“属性”页。
- 点击头像切换角色：刷新模型、名字、武器、属性；选中态与下划线同步。
- 点击左侧“属性”：显示右侧属性区；点击“武器”：打开现有选择武器器（列表 + 详情 + 装备/卸下/确认），菜单高亮切到“武器”；关闭选择器回到“属性”。
- 主按钮/次按钮“更换武器”与菜单“武器”走同一入口。
- Esc/关闭键：选择器打开时先关选择器；否则关闭整个角色页（沿用 `OnCancel`）。
- 场景切换自动关闭（现有 `activeSceneChanged` 逻辑保留）。

## 5. 视觉规范

| 项 | 值 |
| --- | --- |
| 主文字 | `#FFFFFF` |
| 次文字 | `#FFFFFF` alpha 0.85 |
| 强调色 | `#6FE6E6`（选中下划线、等级/数值高亮） |
| 主按钮底 | `#F3E6C8`，文字 `#3A2A12` |
| 次按钮底 | `#000000` alpha 0.28，文字白色 |
| 描边/阴影 | TMP 统一加 2px 深色阴影（alpha 0.85）+ 反向 1.5px 补阴影；右侧再叠渐隐压暗 |
| 分隔线 | 白色 alpha 0.25，1px |

不使用现有的 `panel_round.png` 大面积底板；仅在按钮上使用 `btn_round.png`。菱形图标用旋转 45° 的 `Image`（纯白/青色），不新增图标资源。

## 7. E2E 验收

1. 主页角色按钮打开角色页：背景铺满、无残留深色底板、无 Console 报错。
2. 顶部 2 个头像：选中态下划线与描边正确；点击切换后模型、名字、武器、6 项属性同步刷新。
3. 属性数值 = 基础值 + 已装备加成；增伤/减伤/移速为百分比；未装备武器时显示“未装备武器”。
4. 左侧“属性/武器”切换：高亮正确；“武器”打开选择器，列表/详情/装备/卸下/跨角色确认全部可用。
5. 装备或卸下后关闭选择器，右侧武器名与属性立即刷新。
6. 主按钮“更换武器”与菜单“武器”行为一致。
7. Esc：选择器打开时先关选择器，再按关闭角色页；切场景自动关闭。
8. 1920×1080 下所有文字不截断、数值右对齐；16:9 拉伸无重叠。
9. 录屏或截图对照参考图检查：金色背景、无面板、白字阴影、青色选中态。

## 8. 已确认的取舍

1. 未实现的数据（等级/经验、命座星数、元素徽章、圣遗物/天赋/资料、体力、元素精通）直接不显示，不做禁用占位。
2. 背景用 AI 生成的暖金云海图；头像圆形遮罩与右侧压暗渐变由构建器程序化生成。
3. 武器页重排为独立页签：保留顶部头像与左侧菜单，列表与详情在内容区内切换，不再是全屏弹层。
4. 右下主按钮为“更换武器”，与左侧菜单“武器”走同一入口。

## 9. 实测结论（2026-10-27）

- 预制体重建成功：49 项控件绑定，2 份角色数据，无缺失节点警告。
- 属性页：背景铺满、无旧版深色底板；头像 2 个、选中下划线与当前角色一致；六行属性（生命/攻击/防御/增伤/减伤/移速）可读，数值右对齐。
- 页签：点击“武器”切换后属性区隐藏、武器页显示、主按钮隐藏、菜单高亮切到“武器”；“返回属性”恢复。
- 角色切换：选中索引、下划线、右侧名字、模型三者一致（安比 ↔ 艾莲）。
- 关闭：关闭键与 `OnCancel` 均可关闭页面，`UIManager.IsOpen` 归位。
- 可读性：右侧加 700px 渐隐压暗（最右 alpha 0.42），实测右缘平均亮度 140 → 110；文字统一 2px 深色阴影 + 反向补阴影。
- 预览模型自带武器按节点名隐藏，避免“未装备武器却手持武器”。

已知边界：

- 直接 Play 角色页未登录时显示“请先登录”，装备列表为空；正常登录流程不受影响。
- 预览模型没有装备外观挂点，装备武器只影响数值与武器页信息，不会改变模型手持外观。
- 未做地面镜面倒影（参考图有）；当前用椭圆接触阴影代替。
