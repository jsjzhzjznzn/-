根节点挂 `PanelSkin`：`backgroundKey=bag`（把 `bg_bag.png` 铺到 `BagPanel`，底图本身是好的）、`applyLightTheme=1`、`applyBackdrop=1`。

「丑」的四个根因（均为实测）：

1. **控件根本没被换肤**。`PanelSkin.Recolor` 只翻转亮度 ≤0.32 的深色块，而这批控件亮度刚好全部高于阈值：窗口描边 0.321、未选中页签 0.347、功能按钮 0.373、关闭键 0.437。于是呈现「浅色羊皮纸面板 + 深色扁平网页控件」的混合状态。
2. **未选中页签不可读**。页签底色 #525966 与标签字色 #434039 都是深色，而 `BagView.RefreshTabLook` 只改 `targetGraphic.color`、不改标签字色。
3. **网格贴图铺满整个面板**。`Background` 贴图（奶油白 35% + 土黄 35% 线）覆盖 1440×800 全尺寸，网格线因此出现在详情区与四角手绘装饰上；同时格子填充只有 8% 不透明度，底图的挎包/药水瓶插画会从格子里透出来。
4. **零散风格件**：`WindowFrame` 是 2px 深蓝硬矩形压在插画上；`PreviewSquare` 是无贴图直角近白方块；底部四个按钮不在同一基准线（`加物品/整理` 在 y=22，`使用/丢弃` 在 y=-190）；加载环是蓝色科技圈。

### 1.2 视觉口径

统一色板（与 `UITheme` 对齐，不新增主题概念）：纸底 `#F5EEDC`、描边金褐 `#C2A87A`、强调金 `#D9B25C`、正文深褐 `#4A3B21`、次级字 `#8C8578`、数量角标 `#434039`。

- **页签**：未选中＝米纸底 α0.94 + 金褐描边 α0.85 + 字 `#8C8578`；选中＝暖金纸底 α0.99 + 3px 金褐描边 + 左侧 5×34 金色竖条 + 字 `#4A3B21`。两态用两张贴图切换（`bag_chip` / `bag_chip_active`），不再只靠染底色。
- **格子**：九宫格贴图（**中性白底**：2px 描边 α1.0 + 中心填充 α0.55），运行期由 `BagSlotView` 染色 —— 常态 `#B89E73` 土黄、选中/已装备乘金 `#D9B25C`。中性底使「贴图内容」与「状态染色」解耦，选中态不会被贴图自带颜色压暗。
- **按钮**：四个按钮同一张九宫格纸片贴图，字深褐 18px；交互态显式写在预制体里（正常白 / 悬停 (0.96,0.93,0.87) / 按下 (0.88,0.84,0.76) / 禁用 (0.80,0.77,0.71) α0.55 暖调压暗，不用冷灰）。
- **关闭键**：圆形羊皮纸徽记（外圈 4px 深褐 `#7F6234` + 内纸底 `#E4CE9C` α0.99）+ 深褐「×」。徽记底色与面板纸底**必须拉开**（第一版取 #F8F1E2 与纸底几乎同色，圆环又被 3px 描边吃掉，肉眼几乎看不到按钮）。
- **分隔**：金褐细线 α0.65，中央菱形金饰，两端 56px 渐隐。
- **不做启发式换肤**：本次所有控件颜色在预制体里显式指定。`PanelSkin` 仍负责面板底图与四周虚化底，但其 `Recolor` 阈值（≤0.32）不再承担这些控件——本方案颜色亮度均高于阈值，天然不会被它覆盖。

## 3. E2E 验收项

1. 打开背包：两个页签位于面板**左侧上部**（标题金线下方、格子区左沿）；武器页选中态有金色竖条，道具页无。
2. 点「道具背包」：Console 无报错；格子区行数切换为道具区、容量文案变「N 件（不限格）」；选中态与指示条随页签交换（往返两次均正确）。
3. 文字可读性：未选中页签标签、容量文案、格子数量角标在浅色底上均可读。
4. 切到道具页再切回武器页：可见格子边框颜色一致（模板行与真实行一致）。
5. 交互未回归：点格子选中 → 右侧详情显示名称/类型；拖拽换位仍只在同区生效；「整理」有回执；关闭键点一次即关。
6. 视觉核对（抓帧）：面板上不再有横贯全屏的网格线、不再有深蓝硬边框；右上角有清晰的圆形关闭徽记；四个功能按钮处在同一水平基准线；四角手绘插画（挎包/药水瓶/卷轴）完整可见、不被格子压住。
7. Console 无 error / exception。

## 4. 风险

- **8 列改 7 列**：每屏少一列，500 格 = 72 行（虚拟列表滚动，无功能影响）。武器区容量语义与服务端槽位不变。
- **删除 `Background` 全屏网格层**：底图角落插画比改造前更艳（更接近 `bg_bag.png` 原图），这是刻意达成的效果；若观感过艳，只需把它调回由 `PanelSkin` 提供的半透明虚化底，不需要改格子。
- **`UIControlData` 条目必须与节点删除同步**：否则框架初始化时会去找不存在的目标。构建器负责同时处理。
- **不再依赖 `PanelSkin.Recolor`**：该启发式阈值（≤0.32）对亮度 0.32~0.44 的控件完全无效，是改造前「浅底 + 深色控件」的成因。后续给本面板新增控件时同样要显式指定颜色。
- **贴图全部为构建期产物**：改色/改圆角后必须删掉对应 `.png` 再跑一次 `Tools/UI/重建背包界面`，否则构建器会按幂等规则跳过。
